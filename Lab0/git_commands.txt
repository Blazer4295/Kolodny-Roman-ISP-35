git clone <ссылка> — копирует удалённый репозиторий к тебе на компьютер вместе со всей историей.

git status — показывает текущее состояние: какие файлы изменены, добавлены или готовы к коммиту.

git add <файл> — добавляет изменения указанного файла в так называемую «область подготовленных файлов» (staging area), готовя их к коммиту.

git commit -m "сообщение" — сохраняет подготовленные изменения в истории репозитория с кратким пояснением.

git push — отправляет твои локальные коммиты в удалённый репозиторий.

git pull — скачивает свежие изменения из удалённого репозитория и сразу сливает их с твоей текущей веткой.

git branch — показывает список всех веток в репозитории и выделяет текущую.

git branch <имя> — создаёт новую ветку.

git checkout <ветка> — переключается на другую существующую ветку.

git merge <ветка> — вливает изменения из указанной ветки в текущую.
